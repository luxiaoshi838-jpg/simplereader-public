# v591 多看式固定页面验收

本分支保持 Draft，直至以下条件全部通过。

## 固定样本

- 用户提供的《大道之上.txt》
- 同一 Android 设备
- 多看与简阅使用一致字号、行距、横向边距及可用阅读区域

## 页面轴

1. 每章独立排版并形成固定逻辑页列表。
2. 章末不足一页时保留空白，不把下一章正文补入该页。
3. 下一章标题只能出现在下一逻辑页顶部。
4. 横向翻页和上下滚动必须复用同一 `ReaderPageSnapshot` 与 `ReaderPageAnchor`。
5. 页码、目录跳转、书签及进度恢复必须复用同一页索引。
6. TXT 字符位置必须映射到真实源文件字节边界，不得按字符比例估算。

## 视觉和操作

1. 正文避开状态栏和底部导航栏，并保留稳定上下空白。
2. 上下边缘使用背景同色渐隐，不裁切正文。
3. 章节标题为正文 1.30 倍并加粗。
4. 上下模式保持原生拖动和惯性，但滚动对象是固定页面序列，而不是跨章大文本。
5. 切换覆盖、平移、淡入、仿真和上下模式时，逻辑阅读位置不变。

自动测试和 APK 静态检查不能替代该样本的实体设备视觉验收。
